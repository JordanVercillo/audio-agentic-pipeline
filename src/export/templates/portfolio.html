Methodology. Spotify removed third-party access to its audio features in February 2026 — so this pipeline builds its own:
  • Listening history via the Spotify API (Authorization Code + PKCE — no client secret exists anywhere in the project).
  • Audio acquired per track (rate-limited, idempotent), analyzed locally with librosa into a 77-dimension feature vector.
  • Medallion warehouse (Bronze → Silver → Gold star schema, Parquet) keyed on a single bridge key.
  • Drift = RMS per-feature shift between standardized window centroids, in σ units. Clustering and UMAP run in the same standardized space with fixed seeds — every number in this report is reproducible.
